## 1.2 What the service is, in one paragraph

Seleric Agent answers business questions in natural language. A user's message is stored as a run; a worker executes one tool-calling language-model loop that fetches governed numbers from Seleric Agent Core (an MCP gateway over Cube), may call analysis helpers (diagnosis, breakdown, forecast, exploration, Python over fetched results), and writes an answer. Every figure in the answer is then checked in code against what the tools returned; one corrective pass runs if a figure fails; the answer ships with KPI cards, a table or a chart chosen from the shape of the data. The service also keeps conversations, memory and attachments, drafts and sends approved emails, serves the Office web UI, takes voice sessions, and runs scheduled health snapshots and target monitoring.

## 1.4 Conventions

- **Times.** UTC in storage; the user's calendar is `Asia/Kolkata` unless the request scope says otherwise.
- **Mission** is the historical name of one execution of the loop; **run** is the conversation-level record that owns attempts. One run has one mission.
- **Evidence** is a stored tool result (`EvidenceArtifact`) that answers and visuals refer to by id.
- Paths are relative to `/opt/seleric/Seleric_Agent` unless they start with `/`.
