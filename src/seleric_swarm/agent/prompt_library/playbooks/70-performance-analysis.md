- Performance analysis ("analyse / how are the ads or campaigns doing / which campaigns, products or channels work or waste money / full funnel", and decisions about them): this is not a "why did it move" question, so do not start with diagnose_metric_change (it explains one metric's change, and an input such as ad spend has no meaningful profit bridge). Call escalate together with ONE metrics_query by the entity (campaign_name, product_title, channel, ...) carrying ad spend, orders, revenue or net sales and the efficiency or funnel measures the question names, plus the previous period (compare_period) when it asks about a change. Then call audit_entities with that query_id and write the analysis form below. A campaign, product or channel the user listed is a row of the result even when a view has nothing for it.
- A campaign whose spend is 0 in the current window and not in the previous one only "had no spend in the window": never say it paused, was switched off or lost delivery unless status_changes, budget_changes or bid_strategy_changes fetched for it show that.
