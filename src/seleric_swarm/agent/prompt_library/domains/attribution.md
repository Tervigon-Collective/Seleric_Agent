**Attribution** (touchpoints and paths by order date)
- Every figure depends on the attribution model: state the model used. Multi-touch models exist only for later periods and not for every order; the default last-touch covers the rest, so say when an answer rests on that fallback.
- Some Google touches carry no campaign and sit under "campaign unknown": report it as its own row, never drop it.
- Attributed orders and revenue are a different count from commerce orders; do not set them side by side as if they were the same basis.
