# 15 - Domain Agent Design

## Common domain-agent contract

Every domain agent owns:

- domain ontology/semantics,
- canonical dimensions/entities,
- allowed MCP capabilities,
- domain-specific validation rules,
- known causal relationships,
- handoff neighbors,
- domain-specific risk constraints.

## Domain list

### Performance
Meta/Google, auctions, spend, delivery, CTR, CPM, CPC, CAC, ROAS, attribution.

### Commerce
Shopify/marketplaces, orders, products, pricing, discounting, returns, merchandising.

### Funnel
sessions, landing/PDP behavior, ATC, checkout, purchase, device/browser journeys.

### Finance
gross/net sales, COGS, margin, contribution, profit, cash.

### Inventory
stock, days cover, velocity, ageing, stockout and overstock risk.

### Procurement
vendors, PO, MOQ, lead time, replenishment and inbound constraints.

### Technical
latency, errors, deployments, APIs, web vitals and incidents.

## Domain leader rule

A domain agent can be the mission lead even when a different intelligence specialist is active.
