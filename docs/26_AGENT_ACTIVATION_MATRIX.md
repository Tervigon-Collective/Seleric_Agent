# 26 - Agent Activation Matrix

| Query type | Domain lead | Specialists normally activated |
|---|---|---|
| Sales yesterday | Commerce | Observer, Skeptic-lite/claim gate |
| ROAS comparison | Performance | Observer |
| What changed? | Relevant domain | Observer, Anomaly |
| Why did it change? | Relevant domain | Observer, Anomaly, Diagnostic, Skeptic |
| What happens next? | Relevant domain | Observer, Prediction, Skeptic |
| What should we do? | Relevant domain | Observer, Diagnostic, Prediction if needed, Strategy, Skeptic |
| Cross-domain root cause | Initial closest domain | Observer, Anomaly, Diagnostic + dynamic handoffs + Skeptic |

## Principle

Activate the minimum set that can satisfy the evidence requirements. Agent count is not intelligence quality.
