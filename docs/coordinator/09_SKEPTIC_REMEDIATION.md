# 09 — Skeptic Remediation

REVISE is unresolved work, not a disclaimer on an accepted conclusion.

Coordinator maps `FollowUpTask` capabilities to **targeted** tasks:

| Kind | Action |
| --- | --- |
| missing causal graph | CausalGraphRegistry resolve + causal validation only |
| missing evidence | Observer / domain |
| model drift / forecast metadata | Prediction reevaluate only |
| strategy constraint | relevant domain |

**Never** blindly re-run entire Diagnostic for a missing graph.
