# Tickets

One file per ticket, `TICKET-NNN.md`, IDs never reused. Lifecycle:
BACKLOG → READY → IN_PROGRESS → REVIEW → DONE (or BLOCKED at any point).

Create a ticket when work is actually about to start — not speculatively
for every line item in the spec docs. The spec docs (02, 05, 06, 10) are
already the detailed requirements; a ticket scopes *this session's* slice
of that plus acceptance evidence, it doesn't re-write the spec.
